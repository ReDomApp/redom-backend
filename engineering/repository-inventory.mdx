## Core backend subdirectories

Within `artifacts/redom-backend/src`:

- `routes/`: HTTP route modules and route registry.
- `controllers/`: request controllers.
- `services/`: product and domain services.
- `database/`: schema and data-access modules.
- `middleware/`: authentication, authorization, and request middleware.
- `lib/`: integrations and shared clients.
- `config/`: environment parsing, pricing, and provider configuration.

## Shared libraries

The current workspace tree includes:

- `lib/api-client-react`
- `lib/api-spec`
- `lib/api-zod`
- `lib/db`

Inspect each package's own README, exports, and package manifest before documenting its public API.
