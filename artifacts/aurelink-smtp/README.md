# Aurelink SMTP Relay

This is a separate TCP SMTP submission service. It is not part of the HTTP API process because public SMTP requires a TCP endpoint and TLS certificate.

## Provider routing

- Primary: Resend SMTP at `smtp.resend.com:465` (username `resend`, password = Resend API key).
- Fallback: Brevo SMTP at `smtp-relay.brevo.com:587` (SMTP login + SMTP key; a Brevo REST API key is not accepted).
- The relay attempts Brevo only after Resend rejects/fails the SMTP transaction.
- A sender domain must be verified in Aurelink against both Resend and Brevo before it can use this two-provider SMTP route.

## Deploy requirements

Use a TCP-capable host with public inbound TCP 587 and outbound TCP 465/587. Render web services expose one public HTTP port, not an arbitrary public SMTP port. Render free services also block outbound SMTP ports 25/465/587; paid services are required for outbound SMTP. See Render networking restrictions before choosing the host.

Required environment:
- `DATABASE_URL`: same Neon database used by the Aurelink backend.
- `SMTP_PORT=587`
- `SMTP_TLS_KEY` and `SMTP_TLS_CERT`: PEM contents or file paths for the SMTP hostname certificate.
- `AURELINK_RESEND_API_KEY` (or `RESEND_API_KEY`)
- `AURELINK_BREVO_SMTP_LOGIN`
- `AURELINK_BREVO_SMTP_KEY`
- `AURELINK_SMTP_PRIMARY_PROVIDER=resend`
- `AURELINK_SMTP_FALLBACK_PROVIDER=brevo`

## Safety controls

- SMTP AUTH is mandatory and STARTTLS is mandatory.
- SMTP usernames/passwords are generated by the Aurelink API; passwords are stored as scrypt hashes and shown once.
- Sender domains must be verified by both providers; arbitrary From domains are rejected.
- Message size, recipients, per-minute throughput and daily send counts are capped.
- No unauthenticated/open relay is provided.

Configure a DNS A/AAAA record for the SMTP hostname to this service and publish the appropriate SPF/DKIM/DMARC records for each provider. Do not point the domain's MX records at this submission service: it is an authenticated outbound relay, not an inbound mailbox server.
