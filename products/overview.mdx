## Other workspaces

`redom-about`, `redom-help`, and `redom-docs` contain public information, help-center, and documentation application assets. Shared packages are under `lib/`; automation and repository utilities are under `scripts/`.

<Warning>Workspace membership describes tracked source organization. It does not certify production deployment, uptime, external provider connectivity, or feature completeness.</Warning>
